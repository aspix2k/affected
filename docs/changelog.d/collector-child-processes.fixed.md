- Gradle and Maven exact selection: a test that runs project code in another process — a child JVM started with `ProcessBuilder`, Gradle TestKit, a command-line tool under test — left no trace of that code in its dependency map, so it could be skipped when the code changed, and a change used only that way reported "proven-empty" and ran nothing. A test class that starts a process during its run is now selected with every change; a process started outside any test turns exact selection off for that task.
